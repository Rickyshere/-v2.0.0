============================================
  普速铁路中转方案 — 使用说明
============================================

【如何运行】
  1. 确保电脑已安装 Python 3.9 或更高版本。
     - 没有的话去 https://www.python.org/downloads/ 下载安装，
       安装时务必勾选 "Add Python to PATH"。
  2. 双击运行  「启动服务.bat」。
  3. 脚本会自动：检测 Python → 安装依赖(首次需联网) → 启动服务
     → 自动打开浏览器。
  4. 浏览器里输入起点、终点，点「查询方案」即可。

  （macOS / Linux 用户：在终端运行  bash 启动服务.sh）

【停止服务】
  关闭弹出的「普速铁路服务」窗口即可。

【功能提示】
  - 每个方案卡片顶部有「直达推荐」：自动查询起点→终点直达车次。
  - 若有多趟直达车次，地图默认展示「耗时最短」一趟的真实经停站，
    沿这些站点画绿色折线、每站标绿色圆点（点开看站名和到开时间）。
    中途站点只重点展示「特等 / 一等 / 二等」大站，县级小站不点缀。
  - 方案内可自定义任意两站区间查车次（如 昆明→鹰潭）。
  - 车次查询为实时数据，来自 12306，仅供参考。

【已选车次：分段拼中转方案（A-B-C）】
  自己设计中转方案时，可以先把每一段的心仪车次「钉」起来，边查边比。

  ① 查询任一段车次（如 北京→武汉）后，每条车次前面都有一个勾选框。
  ② 勾选想要的那趟 → 它会被钉到右侧「已选车次」面板里，
     显示车次号、区间、日期、发到时间、历时与是否可预订。
  ③ 接着查下一段（如 武汉→广州）时，「已选车次」面板不会被清空，
     两段车次可以并排对照，方便判断接续时间是否来得及。
  ④ 若两段首尾相接（A→B 且 B→C），面板顶部会自动给出
     「换乘链：A → B → C」的提示。
  ⑤ 面板上的「✕」移除单条，「清空」清空全部，「收起 / 展开」折叠面板。
  ⑥ 已选车次保存在浏览器本地，刷新页面、重开浏览器都不会丢。

  提示：勾选框在「直达推荐」和每个方案的「自定义区间」查出的车次列表里都有。

【本地添加 / 修改铁路线（网页内即可完成）】
  支持直接在网页里增删、修改铁路线，保存后立即生效，
  无需重启服务、无需碰代码。

  ① 打开网页后，点击顶部导航的「线路管理」按钮，会弹出独立的编辑界面。
     之前右侧的「新增站点」入口已并入这里。
  ② 点击「加载线路」→ 文本框会显示当前的线路清单。
  ③ 按下面的格式新增或修改线路：

       线路名（可加注释）：站名（等级）、站名（等级）、站名（等级）...

     示例：
       南昆线（连接：南宁、昆明）
       南宁站（一等）、百色站（二等）、兴义站（二等）、昆明站（一等）

       京广线（连接：北京、广州）
       北京西站（特等）、石家庄站（一等）、郑州站（特等）、
       武汉站（一等）、长沙站（一等）、广州站（特等）

     说明：
       - 等级支持：特等 / 一等 / 二等 / 三等（不带"站"字也认）。
       - 线名用「（）」括起来的文字会被当作注释，不影响线路名。
       - 支持换行，每条线路用空行隔开。
       - 想单独加一个站点：把它作为一条线路的第一个站即可。

     ⚠ 常见写错：把线名注释混在站点列表里，例如
         浙赣铁路：南昌站（一等）、鹰潭站（特等）、浙赣铁路（连接：南昌）
       末尾那截会被当成一个叫「浙赣铁路」的"站点"，生成后成为缺坐标站。
       程序现在会识别并忽略这类片段（括号内不是合法等级），生成时给出提示。
       正确写法：线名单独写在最前面。
  ④ 点击「保存并重新生成」→ 数据会重算并即时生效，
     界面下方会显示「共 X 个站点、Y 条连接」。
  ⑤ 关闭弹窗，重新输入起止地点查询，即可使用新线路规划方案。

  【如果直接改了本地 txt 文件】
    你也可以直接用记事本编辑项目里的 main_railway_line.txt，
    然后回网页点「线路管理」里的「从文件重新生成」按钮，
    同样立即生效。

    说明：只要你还**没有在编辑框里输入过内容**，每次打开「线路管理」
    都会自动重新读取文件，所以能看到记事本里的最新修改。
    若你已经在编辑框里改过，弹窗会保留你的编辑（不会覆盖），
    想放弃编辑重新读取，点「加载线路」即可。

【查看所有铁路线路（线路总览）】
  顶部导航的「线路总览」按钮，点击后**直接在地图上显示全部铁路线路**：
  ① 所有线路一次性画出，每条用**不同颜色**的折线标识，站点用小圆点同色标出。
  ② 鼠标移到站点圆点上，可看到站名和所属线路。
  ③ 右上角有「铁路线路图例」，显示每种颜色对应哪条线路；
     点击某个线路名，可单独显示 / 隐藏那条线；
     图例顶部还有「全显」「全隐」按钮，一键显示/隐藏所有线路。
  ④ 地图会自动缩放到能看全所有线路的范围。
  ⑤ 再点一次「关闭总览」按钮（或按 Esc），清除所有线路，
     恢复显示之前查询的方案。
  ⑥ 新增 / 修改线路并保存后，总览会**自动刷新**，新线路立即出现，
     不需要刷新页面、也不需要重新点开关。
  ⑦ 若某条线在图例末尾被标为「未显示（站点缺坐标）」，
     说明这条线有站点还没有经纬度，请参照下一节补全坐标。

【新增线路，但站点没有坐标怎么办？】
  如果在 txt 线路清单里添了新线，有些站可能没有经纬度，画不出正确图形。
  这类站点**不会参与算路**（所以不会算出错误里程），但需要补全坐标才能用。

  ── 方式一（推荐）：网页里一键补全 ──
  ① 先把百度地图开放平台的「服务端 AK」设为系统环境变量 BAIDU_AK
     （设置方法见本文件最后「附：配置百度服务端 AK」）。
  ② 打开网页 →「线路管理」→ 勾选底部的：
        ☐ 是否启用在线地理坐标补全，需提供百度地图开放平台服务端AK
     开关下方会显示 Key 是否就绪、当前有哪些站缺坐标。
  ③ 点「保存并重新生成」或「从文件重新生成」，
     缺坐标的站会被自动补全，并在下方反馈里列出补全结果。
  说明：
    - 只在**确实有缺坐标站点**时才会联网调用，坐标齐全时不会消耗额度。
    - 百度同一 AK 并发上限是 3，程序已做硬性限制，不会超。
    - 补全结果存在 extra_coords.json，一次补全永久生效。

  ── 坐标复核：看到「相邻站间距异常大」怎么办 ──
  保存线路后，如果反馈区出现这样的提示：

      ⚠ 2 处相邻站间距异常大，请确认坐标是否正确：
        中华门 — 马鞍山：1143.6 km（宁铜铁路）

  说明某个站的坐标可能被在线地图解析到了**异地同名**的地方
  （例如「马鞍山」曾被解析到广东境内，而真实的马鞍山在安徽）。
  这类错误坐标看上去完全正常（不是 0,0），靠程序自动判断会误伤
  兰新线（乌鲁木齐—西宁 1441km）、青藏线（拉萨—格尔木 828km）
  这些真实存在的长区间，所以程序**只提示、不自动改**。

  处理办法：
    - 若该区间确实很长（如兰新线、青藏线），忽略即可。
    - 若是短途支线却出现几百上千公里，说明坐标错了：
      打开 extra_coords.json，把该站的经纬度改成正确值，
      然后回网页点「从文件重新生成」即可。

  ── 方式二：命令行 ──
  在项目目录打开命令行：

      自动补全坐标并重新生成：
        python upgrade_data.py --fetch

      或分两步，先只查看缺坐标的站：
        python fetch_coords.py

      自动在线爬取 + 交互输入（推荐国内配在线 Key）：
        python fetch_coords.py --fix --amap-key=你的高德Key --baidu-ak=你的百度Key
        或用环境变量（推荐，避免 Key 出现在命令行里）：
        set AMAP_KEY=你的高德Key        (Windows)
        set BAIDU_AK=你的百度Key
        python fetch_coords.py --fix

  说明：
    - 工具会先自动尝试在线爬取（高德/百度需 Key，Nominatim 免费但国内可能超时），
      爬不到时进入交互模式，会让你输入「经度,纬度」。
    - 补全结果保存到 extra_coords.json，一次补全永久生效，
      以后 upgrade_data.py 会自动读取，无需再手填。
    - 像上面这样，把缺的站补全后重新生成，地图上就能画出正确的线路了。
    - 安全：本项目不硬编码真实 Key，请勿把自己的 Key 写死进代码提交；
      百度需「服务端 AK」才能用（浏览器端 AK 会返回 status=240）。
  （网页「线路管理」里保存线路后也能用同样命令补全。）

【同城异站：两个站同属一个城市，怎么连起来？】
  同一个城市常有多个车站，例如 芜湖站 / 芜湖南站、铜陵站 / 铜陵西站。
  如果它们没有归并，而恰好又是两条铁路的端点（宁芜铁路止于芜湖南、
  皖赣铁路起于芜湖），那两条线就**接不上**，算路会绕一大圈。
  程序分两层自动处理：

  ① 自动归并（默认开启，不用管）
     只要两个站名有**前缀关系**（芜湖 / 芜湖南、铜陵 / 铜陵西），
     且距离不超过 25 公里，就会自动当成同一个城市。
     打开「线路管理」，在「同城异站归并」里能看到本次自动归并了哪些。

  ② 手工补充（站名没有前缀关系时）
     像 中华门 / 南京、广安门 / 北京 这种，站名看不出关系，
     但确实同城。把它们写进项目根目录的 same_city.json：

         {
           "manual": {
             "中华门": "南京",
             "广安门": "北京"
           }
         }

     注意：JSON 不能写注释，所以**以下划线开头的键会被忽略**，
     可以拿来当备注用（如 "_说明": "..."）。
     改完保存，回网页点「从文件重新生成」即可生效。

  ③ 待确认的邻近站对
     「线路管理」里还有一个可展开的「查看待确认的邻近站对」，
     列出"距离很近但还没归并"的站对，供你判断。
     程序**只提示、不自动合并**，因为里面既有真同城
     （中华门—南京 5.5km），也有不同城市
     （西安—咸阳 21km、太原—榆次 23.6km），机器分不清。
     距离 18 公里以上的会额外标注提醒。

  ⚠ 提醒：手工合并前最好先看看效果。实测把「月山」并进「焦作」，
    会让焦作从二等站升到一等站、失去"就近接入"的虚拟边，
    反而让部分线路变长 1362 公里。

【铁路电报码：为什么有的站查不到车次？】
  12306 的余票查询接口只认**电报码**（如 北京=BJP、芜湖=WHH），
  不认中文站名。所以**没有电报码的站查不到车次**，
  查询时会提示「出发站「××」或到达站「××」无有效电报码」。

  - 对照表是 station_codes.csv，网页「线路管理」里的「铁路电报码」
    区块会显示覆盖率，并列出没有电报码的站。
  - 没有电报码的多为**货运 / 技术站**（南仓、双桥、星火、广安门、
    马头等），它们本来就没有客运码，属正常，不影响算路。

  新增线路后想补全电报码（在项目目录打开命令行）：

      python gen_station_codes.py

  它会从 main_railway_line.txt 取站点、从 station_name.js（12306 站名库）
  取电报码，重新生成 station_codes.csv。跑完重启服务即可生效。

  【票价查询】
  表单里勾选「增加票价查询功能」，车次列表每行下面就会多出一排票价：

      1461  11:59 → 06:45  18:46  可预订
         无座*¥156.5  硬座¥156.5  硬卧¥283.5  软卧¥455.5

  - 票价**不额外发请求**：12306 返回车次时就带上了票价字段，程序只是多解析了一下。
  - 带 * 的是**推导值**：无座票价和硬座（普速）/ 二等座（动车）相同是铁路规则，
    12306 的返回里没有无座这一项，所以程序按规则推出来并标了星号。
  - 不勾选就不解析，页面更清爽。

  「直达车次」和「推荐方案」里的票价**默认是收起的**，点「▸ 票价」才展开，
  免得一上来就被一堆价格占满。这两处不受上面的勾选框影响，
  数据始终会带（反正不额外发请求），只是折叠起来而已。

【高速动车组页面（G / D / C）】
  页面右上角可以切换「普速列车 / 高速动车组」两个页面：

      普速列车   ——  K / Z / T / Y / 纯数字，路网是人工维护的线路清单
      高速动车组 ——  G / D / C，路网是「八纵八横」16 条主通道（车站级）

  两个页面功能完全一样：方案查询、地图、查车次、直达、票价、已选车次、
  推荐方案、通道总览都能用。切换时会清空上一个页面的结果，避免混淆。

  说明：
    - 八纵八横的路网是**车站级**的（641 个车站 / 35 段通道）。
    - 里程是「相邻车站直线距离」之和，与真实线路里程**有偏差且方向不定**
      （实测 15 条主要干线：-19% ~ +15%，平均 -7%）。这**不是精确里程**，
      准确里程以 12306 为准。
    - **在建段默认不参与算路**：数据里给尚未通车的通道加了 [在建] 前缀
      （当前 5 段：京沪二线津潍段 / 潍宿段 / 北沿江段、京港台雄商段、
      京昆雄忻段）。这些段的车站还在地图上，但不会出现在方案里，
      免得给出查不到车次的路线。
      想连在建段一起算：POST /api/hsr/reload?include_planned=true。
    - 如果查的站只在建段上（如 东营南、滨州、泰州），会明确提示
      「目前只出现在在建通道「××」上，暂无车次」。
    - 车站表是人工整理的主要车站，经过「相邻站间距」自动校验，
      但不保证是官方完整站表。
    - 通道数据在 hsr_network.txt，可以直接编辑；改完调一次
      POST /api/hsr/reload（或重启服务）即可生效。

【推荐方案（直达 / 中转）】
  点表单里的「推荐方案」按钮，系统会：
    1. 先查有没有直达车次；
    2. 再用路网图找出候选换乘大站，分别查「起点→枢纽」和「枢纽→终点」；
    3. 只保留**接续时间不少于 1 小时**的组合，按总耗时排序给出前几条。

  例：

      推荐方案：哈尔滨 → 南宁 · 2026-09-25（中转接续不少于 60 分钟）
        中转  K4696 04:59→07:29 ＋ Z398 10:00→23:59   经 长春，接续 2h31m

  注意：
    - 这个功能要查好几次 12306（1 次直达 + 每个枢纽 2~3 次），
      受限速影响**大约要等 10 秒**，属正常。
    - 普速车常常跨天（比如 北京→南京 的 1461 次 11:59 发、次日 02:56 到），
      所以第二程会**同时查当天和第二天**的车次，否则普速中转基本都排不出来。
    - 接续时间下限默认 60 分钟，可在请求里用 min_transfer 调整。

【临时加一个数据里没有的站】
  如果某个站不在线路清单里，可以临时把它加进来：
    「线路管理」→ 底部「动态加站（临时）」→ 填 站名 / 经度 / 纬度 / 等级
    → 点「加站」。
  新站会自动接入**最近的大城**，然后就能直接查询它了。

  ⚠ 注意：这样加的站**只在内存里，重启服务就没了**。
    要长期保留，请把该站写进 main_railway_line.txt（格式见本文件前面）。
    如果只是临时查一次，用这个表单最方便。

【局域网 / 给朋友访问】
  1. 保持这个程序运行。
  2. 在防火墙中放行 8000 端口。
  3. 让对方浏览器访问： http://你的电脑IP:8000
     （查看本机 IP：命令行输入 ipconfig，找 IPv4 地址）

【附：配置百度服务端 AK（用于在线地理坐标补全）】
  1. 到百度地图开放平台 https://lbsyun.baidu.com/ 申请 AK，
     必须选「服务端」类型（浏览器端 AK 调地理编码会报 status=240）。
  2. 设为 Windows 用户级环境变量（无需管理员）。在 PowerShell 里执行：

       [Environment]::SetEnvironmentVariable('BAIDU_AK', '你的服务端AK', 'User')

     或者在「此电脑 → 属性 → 高级系统设置 → 环境变量」里，
     于「用户变量」新建一项：变量名 BAIDU_AK，变量值填你的 AK。
  3. 设好后**必须重启服务**（关掉服务窗口，重新双击「启动服务.bat」）才会生效。
  4. 回到网页「线路管理」，开关下方应显示「✓ 已检测到 百度 服务端 AK」。

  说明：
    - 本项目不硬编码任何 Key，请勿把 AK 写进代码提交到公开仓库。
    - 额度有限，程序只在确有缺坐标站点时才联网，坐标齐全时不会消耗额度。
