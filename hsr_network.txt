# ============================================================
# 八纵八横高速铁路通道（车站级）
# ============================================================
# 依据：2016 年《中长期铁路网规划》提出的「八纵八横」高速铁路主通道。
#       8 条纵向 + 8 条横向，共 16 条，另含若干支线，合计 27 条。
#
# 格式（每行一条通道）：
#       通道名：车站1、车站2、车站3、…
#
# 关于粒度与准确性（**请先读这段**）：
#   - 这是**车站级**骨架，目的是让里程接近真实（城市级时 北京→上海 只有
#     1067km 直线距离，而京沪高铁实际 1318km，误差约 19%）。
#   - 车站序列为**人工整理的主要车站**，取自各通道对应高铁线路的公开资料，
#     并用「相邻站间距合理性」自动校验过（见 hsr_planner.find_suspect_edges()）。
#     **不代表官方完整站表**：部分县级小站、以及近年新开的车站可能未收录。
#   - ⚠ **部分通道段仍在规划 / 建设中**（如京沪二线的天津—潍坊段、京雄商、
#     雄忻等）。这些规划站点也收录了，但 12306 上**查不到车次**。
#     因此算路可能给出"走在建段"的方案，表现为查车次无结果。
#   - ⚠ 里程 = 相邻车站直线距离之和，比实际线路里程**低约 5~15%**（线路是弯的）。
#     车站级之后误差已从城市级的 -19% 收窄到 -2%~-10%，但**不是精确里程**。
#   - 沿海通道等「复合通道」由多条高铁串联而成（丹大→哈大→秦沈→津秦→
#     京沪→青盐→沪苏通→沪杭→杭甬→甬台温→温福→福厦→厦深→广珠→深茂→
#     茂湛→钦北防），这里按**贯通的站序**排列。
#   - 坐标来源：stations.csv（普速已有）> extra_coords.json（在线地理编码补全）。
#     新增车站用百度地图开放平台地理编码补全（并发 ≤3）。
#
# 改完这个文件后，调用 POST /api/hsr/reload 热重载（或重启服务）。
# ============================================================
